Help Center

Set up AODexa and get answers to common questions.

Get started

  1. Install and launchInstall AODexa from the Microsoft Store. On first launch it opens Settings so you can pick widgets and preferences.
  2. Choose your widgetsOpen the Widget Gallery, preview a layout and select it. Changes apply immediately on the AOD screen.
  3. Set your idle timeIn Settings → Auto-Idle Mode, turn it on and choose how many minutes of inactivity start the display. The default is 3 minutes.
  4. Run on startupAODexa starts with Windows. To change this, go to Windows Settings → Apps → Startup.

Frequently asked questions

How do I turn the AOD on or off?

Press ScrollLock or Ctrl + Shift + G. You can also use the AOD toggle on the AODexa home screen.

How do I close the AOD?

Move the mouse, press any key, or use either shortcut again. The display closes and returns you to the desktop.

The AOD doesn’t start automatically. What should I check?

Make sure Auto-Idle Mode and the AOD Master Switch (the top toggle) are both on in Settings. AODexa must also be running in the system tray.

Does AODexa need an internet connection?

No. AODexa works fully offline. Weather and prayer times were removed in the latest update.

Where is the AODexa icon?

AODexa lives in the system tray, near the clock. Click the icon to open Settings, or right-click it for the quick menu.

How do I quit AODexa completely?

Right-click the tray icon and select Quit. The app stops and leaves the tray.
