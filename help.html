Getting Started
1

Install & Launch

Install AODexa from the Microsoft Store. On first launch the app opens in Settings so you can pick your widgets and configure preferences.

2

Choose Your Widgets

Open the Widget Gallery, preview each layout, and tap the one you want. Changes apply immediately on the AOD screen.

3

Set Your Idle Time

In Settings → Auto-Idle Mode, turn it ON and choose how many minutes of inactivity should trigger the display. Default is 3 minutes.

4

Run on Startup

AODexa is set to launch automatically with Windows so you never miss it. You can disable this in Windows Settings → Apps → Startup.
