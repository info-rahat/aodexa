How to Report a Bug
01

Describe the Problem

What happened? What did you expect to happen instead? Be as specific as possible.

02

Steps to Reproduce

Tell us exactly what you did before the problem occurred so we can reproduce it.

03

Your System Info

Include your Windows version (Win 10 / Win 11) and AODexa version from the About page.

04

Attach a Screenshot

If you see an error message or visual glitch, a screenshot speeds up diagnosis greatly.

Before You Contact Us

Please check the Help page first — most common issues are covered there. For auto-idle problems, ensure AOD Master Switch and Auto-Idle Mode are both enabled in Settings. For startup issues, make sure the app is running in the system tray.
